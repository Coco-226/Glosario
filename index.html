Algoritmo:

Un algoritmo es un conjunto de operaciones que busca resolver un problema determinado a través de secuencias lógicas. Este procedimiento esquemático emplea una serie de pasos, como una receta, los cuales pueden ser formulados de diferentes maneras cuidando que en dicha combinación no se produzca una ambigüedad. La principal utilización de estas fórmulas es que su resultado muestre el punto o destino buscado a través de las secuencias de instrucciones previas, definidas por su programador o diseñador. Entendiendo al algoritmo como un medio, podemos decir que para operar como tal debe ser:

  • Preciso: cada paso y su orden de realización deben ser claros y concretos
  • Definido: se deben obtener resultados delimitados a las órdenes y estos siempre deben ser los mismos
  • Finito: su diseño debe tener un número limitado de pasos
  • Ordenado: la secuencia de pasos debe seguir un orden que no puede ser alterado

Archivo ".BAT":

Un archivo BAT, también conocido por la extensión .BAT o nombre abreviado de «archivos por lotes», es un archivo de texto que representa una cadena de comandos para que el sistema operativo de tu ordenador los ejecute posteriormente. Los archivos .BAT se suelen utilizar para sistemas operativos Windows y pueden abarcar desde operaciones básicas hasta las más complejas. El objetivo principal de estos archivos es automatizar tareas repetitivas.


Archivo:

Un archivo es una colección de datos almacenados en un sistema informático.Por lo general, estos archivos se utilizan para almacenar información sobre usuarios, aplicaciones de software u otros datos necesarios para ejecutar programas.Los archivos también se pueden usar para almacenar imágenes, videos, música y otros tipos de medios.Además de esto, los archivos también pueden almacenar bits de código o instrucciones que permiten a la computadora realizar ciertas tareas.



Hay muchos tipos diferentes de archivos que existen en el mundo informático de hoy.Estos incluyen documentos de texto (.txt), hojas de cálculo (.xls), fotos (.jpg), archivos de video (.mp4) y archivos de audio (.wav).Cada uno tiene un propósito importante para diferentes escenarios, como el trabajo de oficina o los proyectos multimedia.Además, hay varios tipos de formatos de archivo comprimidos como .zip y .rar, que pueden almacenar múltiples archivos más pequeños en un archivo grande.Esto reduce el tamaño y hace que sea más fácil transportar o compartir con otros a través de las redes.


Bloque:

En tecnología, un bloque es como un elemento básico para la gestión y el procesamiento de datos. Es una forma de dividir grandes cantidades de datos o tareas complejas en fragmentos más pequeños, lo que facilita su manejo y el trabajo eficiente con ellos.


Bucle:

Un bucle o ciclo, en programación, es una secuencia de instrucciones que se ejecuta repetidas veces mientras se cumpla la condición asignada al bucle


Carpeta:

Una carpeta es un elemento organizativo en tu computadora. Sirve para almacenar archivos, subcarpetas y otros datos relacionados, permitiendo que mantengas todo bien organizado y fácil de localizar.


CMD:

El CMD de Windows, también conocido como "símbolo del sistema", es una herramienta que permite a cualquier usuario ejecutar comandos de texto para realizar diferentes tareas en el sistema operativo de Microsoft. CMD es muy útil para tareas de administración, automatización y solución de problemas en Windows.


Comando:

instrucción directa y específica que se le da a una computadora, sistema operativo o programa para que realice una tarea concreta. Funciona como una orden que el sistema procesa de inmediato.


Condicional:

Una condicional es una herramienta en programación que permite ejecutar diferentes instrucciones dependiendo de si una condición lógica es verdadera o falsa. En esencia, el programa decide qué decision tomar basándose en las condiciones que se cumplan.


Constante:

Una constante en programación es un valor fijo que no puede cambiar mientras el programa está funcionando. A diferencia de las variables, cuyo contenido puede variar, las constantes sirven para guardar datos que deben ser siempre iguales.


Copy:

El comando copy en el símbolo del sistema (CMD) de Windows sirve para copiar uno o varios archivos de una ubicación a otra.


CSS:

CSS son las siglas en inglés de Cascading Style Sheets, que significa “hojas de esilo en cascada”. Es un lenguaje que se usa para estilizar elementos escritos en un lenguaje de marcado como HTML.


Echo:

El comando echo en la consola de comandos (cmd) sirve para mostrar textos en la pantalla, crear o modificar archivos y controlar si los comandos se ven o se ocultan mientras corre un programa o script (archivo .bat).


Etiquetas:

fragmento de código utilizado como marcador para indicarle a un navegador web cómo debe estructurar, organizar o mostrar el contenido de una página (como textos, imágenes o enlaces).


Extension:

Una extensión de archivo es un grupo de tres o cuatro letras al final del nombre de un archivo. Está separada por un punto. Le dice a tu computadora qué tipo de archivo es. También le ayuda a saber qué programa usar para abrirlo.


GoogleDrive:

Google Drive es un servicio de almacenamiento en la nube de Google. Te permite guardar archivos de forma segura en internet para acceder a ellos desde cualquier dispositivo con conexión.

  • Guardar archivos: Guarda fotos, videos, documentos y música en la nube.
  • Sincronizar dispositivos: Accede a tus archivos desde tu celular, tablet o computadora.
  • Compartir carpetas: Envía enlaces a otras personas para ver o editar archivos.
  • Compartir documentos: Incluye herramientas gratuitas como Documentos, Hojas de cálculo y Presentaciones.
  • Trabajar en equipo: Varias personas pueden editar el mismo archivo a la vez.

Mkdir:

MKDIR (que significa "Make Directory") es un comando que se utiliza en los sistemas operativos para crear carpetas o directorios nuevos.Funciona tanto en las terminales de comandos de Windows (CMD y PowerShell) como en los sistemas Linux, macOS y Unix.


Pseint:

PSeint es una herramienta educativa gratuita diseñada para aprender los fundamentos de la programación.
Utiliza un lenguaje intermedio llamado pseudocódigo escrito en español, lo que permite a los estudiantes comprender la lógica de los algoritmos sin tener que lidiar con la sintaxis compleja y estricta de un lenguaje de programación real (como Java, C++ o Python).


Scratch:

Scratch es un lenguaje de programación visual y una comunidad en línea gratuita desarrollada por el MIT.
Está diseñada especialmente para que niños y principiantes aprendan a programar de forma fácil y divertida.En lugar de escribir líneas de código con texto y sintaxis complicada, en Scratch se programa uniendo bloques de colores como si fueran piezas de Lego.


Script:

Un script es un archivo de texto que contiene un conjunto de instrucciones escritas en un lenguaje de programación. El sistema operativo o un programa específico lee este archivo y ejecuta las órdenes de forma automática y secuencial, de principio a fin.

Trabajo colaborativo:

El trabajo colaborativo es una forma de trabajo en la que un grupo de personas comparte sus conocimientos, habilidades y esfuerzos para alcanzar una meta común.A diferencia del trabajo en equipo tradicional donde cada uno hace su parte de forma aislada, en el modelo colaborativo todos los miembros participan activamente en todas las etapas del proyecto, discutiendo, aportando ideas y construyendo el resultado final juntos.

Variable:

Una variable es un espacio en la memoria de la computadora destinado a guardar un dato que puede cambiar durante la ejecución de un programa


Constante:

Una constante es un espacio en la memoria de la computadora que guarda un valor que no cambia nunca durante toda la ejecución del programa.A diferencia de una variable (que es una caja cuyo contenido puedes cambiar), a una constante una vez que le pones un valor al inicio del código, se queda así hasta que el programa termina.


Acumuladores:

Un acumulador es una variable especial cuyo propósito es sumar valores de forma sucesiva a lo largo de un programa.A diferencia de una variable común (que reemplaza su valor viejo por uno nuevo), el acumulador realiza sumas acumulativas. Es decir, toma el valor que ya tenía guardado, le suma una nueva cantidad y guarda el nuevo resultado en sí mismo./p>


HTML:

HTML (siglas de HyperText Markup Language o Lenguaje de Marcado de Hipertexto) es el código que se utiliza para estructurar y organizar el contenido de una página web.No es un lenguaje de programación (ya que no maneja lógica ni variables complejas), sino un lenguaje de marcado que le dice al navegador web (como Chrome, Mozilla o Edge) qué elementos componen una pantalla y dónde deben ir colocados.


CSS:

CSS (siglas de Cascading Style Sheets) es el lenguaje que se encarga del aspecto visual de la página web. Se utiliza para transformar el texto plano y aburrido de HTML en un sitio web atractivo.


JavaScript:

JavaScript (abreviado como JS) es un lenguaje de programación real y el cerebro de la página web. Permite crear contenido dinámico y hacer que el sitio responda a las acciones del usuario.


Visual studio code:

es un editor de código fuente gratuito y de código abierto desarrollado por Microsoft. Sirve para escribir y editar código de casi cualquier lenguaje de programación.


IDE:

Un IDE (siglas en inglés de Integrated Development Environment o Entorno de Desarrollo Integrado) es un programa informático que reúne todas las herramientas necesarias para escribir, probar, depurar y compilar software en un solo lugar.
